# 語系切換設計

> 細節待 Phase 4 補完。本檔先記錄已決方針。

## 已決方針

- **字典式翻譯**，不採用自動簡繁字符轉換（避免「干支／乾支」等誤轉）。
- 預設語系依 `navigator.language`，使用者覆寫值存 `localStorage`。
- 兩個基本語系：`zh-CN`（與原版字串等價）、`zh-TW`（臺灣慣用詞）。
- API 草案：

  ```js
  import { t, setLocale, getLocale, onLocaleChange } from './i18n/index.js';
  t('lunar.term.lichun');           // '立春' / '立春'
  setLocale('zh-TW');
  ```
