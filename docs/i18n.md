# 語系切換設計

## 設計方針

- **字典式翻譯**，不採用自動簡繁字符轉換（避免「干支／乾支」「头髮／頭髮」等誤轉）。
- 預設語系依 `navigator.language`：`zh-TW`／`zh-HK`／`zh-Hant-*` 走繁體；其餘走簡體。
- 使用者覆寫值存 `localStorage`（鍵 `perpetual-calendar.locale`）。
- 兩個基本語系：`zh-CN`（與原 sxwnl 5.10.3 字串等價）、`zh-TW`（臺灣慣用詞）。
- 條目級字典：以 zh-CN 字串為 key、zh-TW 字串為 value；未列入字典的條目 fallback 為原 zh-CN。

## 公開 API

```js
import {
  t,                // t(key)：以「a.b.c」路徑查當前語系字典
  tFestival,        // tFestival(s)：以 zh-CN 節日字串為 key
  tCity,            // tCity(s)：以 zh-CN 城市／區域字串為 key
  tTimezone,        // tTimezone(s)：以 zh-CN 國家／時區字串為 key
  tStar,            // tStar(s)：以 zh-CN 星座／族名字串為 key
  setLocale,        // setLocale('zh-TW')：切換並通知所有訂閱者
  getLocale,        // getLocale()：取得當前語系
  onLocaleChange,   // onLocaleChange(cb)：訂閱變更；回傳取消函式
  getSupported,     // getSupported()：[{ code, name }, ...]
} from './i18n/index.js';
```

### 範例

```js
t('lunar.terms')[3];                  // '立春' / '立春'
t('eclipse.phases.P1');               // '初亏' / '初虧'
tFestival('春节');                    // '春节' / '春節'
tCity('广东省');                      // '广东省' / '廣東省'
tTimezone('韩国');                    // '韩国' / '韓國'
tStar('天鹰座');                      // '天鹰座' / '天鷹座'
```

## 字典結構

| 命名空間        | 內容                                            | 規模 |
| --------------- | ----------------------------------------------- | ---- |
| `astro.planets` | 行星名陣列                                      | 9    |
| `astro.angle.*` | 度分秒／時分秒單位字符                          | 8    |
| `lunar.*`       | 干支、生肖、節氣、月名、日序、月相              | 200+ |
| `weekday.*`     | 短／全名、前綴                                  | 15   |
| `eclipse.*`     | 日／月食類型、相、量度                          | 30+  |
| `ui.*`          | 14 分頁標題、區段標題、表單欄位、按鈕、提示訊息 | 400+ |
| `festival`      | 公曆固定／按週／農曆節日                        | 200+ |
| `cities`        | 33 區劃，含縣級市、自治州、自治縣等             | 3167 |
| `timezones`     | 254 個國家／代表城市                            | 254  |
| `stars`         | 88 個星座名、8 個族名                           | 96   |

主字典 `src/i18n/locales/zh-TW.js`；地名規模大者分離至 `src/i18n/locales/zh-TW-cities.js`，由 zh-TW.js spread 進來。

## UI 切換

App `header` 右上角下拉選單列出 `getSupported()` 結果，切換時呼叫 `setLocale()`。各分頁透過 `onLocaleChange` 訂閱；回呼中重新呼叫 `mount()` 完整重渲染。

## Wire 位置

- 算法層直接讀 `t()`：`lunar/chinese-base.js`（八字、節日）、`lunar/year-calendar.js`、`lunar/lunar-month.js`、`astro/angle-format.js`
- UI 層讀 `t()`：所有 `src/ui/pages/*.js`、`src/ui/components/city-picker.js`、`src/ui/app.js`
- 節日輸出用 `tFestival`：`lunar/gregorian-base.js`、`lunar/chinese-base.js`
- 城市選單用 `tCity`：`src/ui/components/city-picker.js`
- 星座輸出用 `tStar`：`src/ui/pages/stars.js`（`localizeStarsText` 對輸出文字做替換）

## 字典條目覆蓋

- `cities`：3167 條條目，100% 覆蓋。
- `timezones`：254 條條目，100% 覆蓋。
- `stars`：88 個星座 + 8 個族名，100% 覆蓋。

## 為什麼不採自動簡繁字符轉換

- **歷史包袱字**：簡體「干」對應繁體「干／乾／幹」三字；簡體「头发」對應「頭髮」；簡體「皇后」對應「皇后」（保留），但簡體「之后」（zhīhòu）對應「之後」（後）。地名／節日字串中易踩雷。
- **兩岸術語差異**：例如「乌兹别克斯坦」台灣標準是「烏茲別克」（去「斯坦」尾綴）、「悉尼」是「雪梨」、「老挝」是「寮國」。這類差異無法用單字級轉換實現。
- 字典式雖然需要人工維護條目，但確保翻譯品質可審稿。
